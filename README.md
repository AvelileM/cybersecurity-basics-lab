# Cybersecurity Basics Lab

## About

This is my Cybersecurity solo project for WeThinkCode_.

The goal of this project is to learn and demonstrate basic cybersecurity
concepts using a simple Linux environment.

I am building this project as a beginner and will document the security
concepts, commands, tests, and lessons I learn throughout the project.

## Goals

- Learn basic cybersecurity concepts
- Understand Linux users and permissions
- Learn about basic network security
- Identify simple security risks
- Practice basic security hardening
- Document my findings and solutions

## Technologies

- Linux
- Bash
- Basic networking tools
